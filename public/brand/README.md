# Radoko — logo

Le symbole associe la lettre R à une croix médicale en réserve. Le mot-symbole est entièrement dessiné en tracés SVG : il ne dépend d’aucune police installée.

- `radoko-logo.svg` : version principale, bleu sur fond blanc.
- `radoko-logo-white.svg` : version blanche pour fond bleu ou sombre.
- `radoko-logo-black.svg` : version monochrome pour impression.
- `radoko-symbol.svg` : symbole seul.
- `radoko-logo.png` : version transparente de 1572 × 312 pixels.
- `radoko-brand-board.svg` / `.png` : planche de présentation.

Couleurs : bleu #0876B9 et bleu profond #173B56. Conserver les proportions et une zone libre équivalente à la moitié de la hauteur du symbole autour du logo. Utiliser le symbole seul lorsque la largeur disponible est inférieure à 120 px. Les icônes du site se trouvent dans `app/icon.svg`, `app/favicon.ico` et `app/apple-icon.png`.
